# E5800 screen: developer guide

How the custom touchscreen UI is built, how it talks to the router, and how to change, deploy and debug
it. The user-facing behaviour is in [USER_GUIDE.md](USER_GUIDE.md).

## At a glance

| | |
|---|---|
| Hardware | GL.iNet GL-E5800, firmware 4.10.3, 240×320 SPI touchscreen (`/dev/fb0`, RGB565), touch on `/dev/input/event0` |
| Router | `10.10.1.1`, SSH as `root` with key auth |
| Install dir | `/root/e5ui` |
| Services | `e5ui` (the UI, via `run.sh`) and `homebutton` (power-button watcher), boot order `S13` / `S14` so the screen starts right after the core services instead of at ~66 s (S95); `warm_up()` retries empty data every 5 s for the first 2 minutes |
| Runtime | Python 3.11 + Pillow 9.5. No numpy. `qrencode` CLI for QR codes |
| Footprint | `app.py` ~2,100 lines + `lib.py` ~1,900 lines; ~25 MB RAM; ~1% CPU idle; starts in ~0.6 s cold |

## Files

On this Mac (`~/Documents/e5800-screen`, the source of truth):

| Path | What it is |
|---|---|
| `router/app.py` | The UI: screens, drawing, input, settings. Most changes happen here. |
| `router/lib.py` | Router data and actions copied from [gl-e5800-dashboard](https://github.com/GLiNet-Community-Scripts/gl-e5800-dashboard) (MIT, `LICENSE-upstream`): framebuffer, touch reader, `Refresher`, SIM/Wi-Fi/VPN/SMS/speed-test helpers, GL RPC wrappers. Generated by `tools/extract.py`, then patched (cache dir, toggle path). Edit it directly; regenerating it would drop those patches unless `extract.py` reapplies them (it does for the two current ones). |
| `router/run.sh` | Crash-retry wrapper. Restarts the app after a crash; after 3 crashes in a row it starts the stock `gl_screen` and exits. A run longer than 5 minutes resets the count. A clean exit (SIGTERM → rc 0) stops it. Logs with tag `e5ui`. |
| `router/toggle.sh` | `on` / `off` / `status`: swaps the `e5ui` and `gl_screen` services (enable/disable, so the choice survives reboots). |
| `router/screen_sleep.sh` | `on` / `off` / `toggle`: real screen sleep (backlight, `bl_power` and `fb0/blank`); remembers brightness in `.backlight_saved`. |
| `router/button_watch.py` | Power button: tap = `screen_sleep.sh toggle`; hold ~1 s = switch UI. While this UI runs, a hold writes `/tmp/dashboard_ui_switch_request` and the app shows a confirm sheet. |
| `router/init.d/e5ui`, `router/init.d/homebutton` | procd service files for `/etc/init.d/`. |
| `tools/extract.py` | Copies named top-level defs (plus everything they use) out of the upstream `dashboard.py`. |
| `tools/dashboard_upstream.py` | The upstream plugin source that `extract.py` reads. |
| `prototype/Main.dc.html` | The clickable design prototype ([canvas](https://claude.ai/artifact/KszmJnj8Cw5w1Nw6EciauN)). |

## How the app works

`app.py` is a single `App` class drawing in immediate mode.

1. **Loop** (`App.run`): every ~15 ms it reads touch, runs `tick()` (bandwidth/CPU sampling, city-search
   debounce, auto lock, the power-button switch request) and redraws when something changed, every 1 s for
   the clock, or at ~15 fps while something animates (spinner, speed test, drag). While the screen is off
   (`lib.is_screen_asleep()`) it idles at 10 Hz and draws nothing; waking sets `locked = True`.
2. **Background data**: `lib.Refresher` runs jobs on one thread and caches results. Screens only ever read
   cached values (`self.g(name)`), so a slow `ubus` or `curl` never freezes drawing. Jobs and intervals:

   | Job | Source | Every |
   |---|---|---|
   | `sim` | `lib.get_sim_status` (data, roaming, airplane, ICCID) | 30 s |
   | `sims` | `get_sims` (slots, carriers, per-slot traffic, slot-2 type) | 30 s |
   | `cell` | `lib._get_active_cell_info` (signal, tech) | 10 s |
   | `rep` | `lib.get_repeater_status` | 20 s |
   | `bands` | `lib.get_band_state` (`modem.get_band_config` + `cellular.modem info` for the supported bands) | 120 s, requested on open |
   | `sms` / `smssent` | `lib.get_sms_messages` (smstools spool) / `lib.get_sent_sms` (`modem.get_sms_list`) | 20 s / 30 s |
   | `wgp` / `wga` | WireGuard peers / active peer | 300 s / 20 s |
   | `ts` | `lib.get_tailscale` (`tailscale.get_config`, plus `get_status` while enabled) | 30 s |
   | `wx` / `aq` | Open-Meteo forecast / air quality | 30 min |
   | `fx` | `lib.fetch_fx` (open.er-api.com, base USD, cached 6 h) | 1 h |
   | `clients` / `acl` | `gl-clients list` / block list | 20 s / 60 s |
   | `wifi` | main and guest band states | 60 s |
   | `agh`, `lpm`, `otg`, `ports` | AdGuard, power, USB, Ethernet port configs | 60–120 s |
   | `usbp` | supported USB protocols | 1 h |

   After an action, call `self.r.request(name)` to refresh a job early, or `self.r.put(name, value)` to
   publish a known value immediately.
3. **Screens**: `render()` calls `v_<view>()` for the current `self.view`. Navigation is `go(view)` (push),
   `back()` (pop) and `tab(view)` (reset to a tab). Everything except Home and the lock screen is drawn,
   then shifted down by `TOP` (8 px) below the status bar; touch targets and scroll areas shift with it.
4. **Touch targets**: drawing code registers `self.btn((x0, y0, x1, y1), fn)`. A tap runs the last-registered
   target containing the point. A vertical drag inside a `rows()` area scrolls it.
5. **Row lists**: `self.rows(y0, y1, rows, key)` draws a scrollable list from tuples, which is how most
   settings screens are built:

   | Row | Tuple |
   |---|---|
   | Section label | `("head", text)` |
   | Tap-through | `("link", label, value, fn)` |
   | Switch | `("toggle", label, on, fn[, pending])` (pending shows a spinner) |
   | Read-only value | `("value", label, value)` |
   | Segmented choice | `("seg", label, options, selected, fn(option))` |
   | Small grey text / body text | `("note", text)` / `("para", text)` |
   | Button / three buttons | `("btn", label, fn, "pri"\|"danger"\|"")` / `("btn3", [(label, fn, style), …])` |
   | One or two tiles | `("tiles", [(title, subtitle, fn), (…)])` |

   | Message | `("msg", from, preview, tag, unread, fn)` |
   | Choose-one list item | `("pick", label, selected, fn[, detail])` (✓ on the chosen one, no chevron; `detail` is dim text before the ✓, e.g. a clock time) |
   | SIM card (SIM page) | `("simcard", draw(y) -> tap action)`, 41 px tall; the callback draws on the scrolling layer |
   | Wi-Fi uplink card (Main list) | `("upcard", draw(y) -> tap action)`, 62 px |
   | Band chips | `("bands", label, supported, picked, prefix, flip(b), flip_all, warn)` |

   The settings sections under More → Router settings live in `set_rows(key)`; add a section there and a
   row in `v_more`.
6. **Actions**:
   - `self.work(label, fn, refresh=(…))` runs `fn` on a thread behind a full-screen spinner.
   - `self.confirm(title, body, yes, fn, danger)` shows a bottom sheet first.
   - Wi-Fi changes use `bg_wifi()` / `rename_guest()` instead: they run in the background, one at a time
     (`wifi_lock`), and show a spinner in the row (`self.pending`).
   - `self.say(text)` shows a 3-second message.
7. **Text and fonts**: `F(size, weight)` loads the stock fonts from `/etc/gl_screen/language/ttf`
   (`m`, `s`, `b`, `mono`). Sizes ≤ 16 are drawn `FONT_BUMP` (3) px larger, and nothing is drawn smaller than `MIN_PX` (13 px; `F()` enforces it, so `F(8)` and `F(9)` are 13 px too). Those fonts lack ⌫/⇧, so the
   keyboard says "Del"/"aA".
8. **Framebuffer**: `to565()` converts with Pillow channel ops and writes to `/dev/fb0` (byte-identical to
   the plugin's numpy version and about as fast). `_safe_rr` patches Pillow 9.5's `rounded_rectangle`, which
   raises on boxes smaller than twice the radius.

## Router APIs

GL's web backends are called outside nginx, with no web login:

- **Lua RPC** (`lib.gl_lua_rpc(path, method, params)`): runs `/usr/lib/oui-httpd/rpc/<module>` through a
  stub (`gl_get` / `gl_set` in `app.py` wrap it).
- **C RPC** (`lib.gl_c_rpc(obj, method, args)`): POSTs to the `/www/cgi-bin/glc` CGI for `rpc/<obj>.so`.

Every call below was copied from the stock web UI's JavaScript in `/www/views/*.js.gz` (search for
`"sid","<module>","<method>"`).

| Feature | Call | Notes |
|---|---|---|
| Switch SIM | C `modem.set_slot_failover_config {bus:"cpu", current_sim:1\|2}` | Same as the web UI's "Use this SIM". |
| Slot 2: SIM2 or eSIM | C `modem.set_slot_type {bus:"cpu", slot:2, type:0\|1}` | 0 = physical, 1 = eSIM. Read via `get_slot_failover_config` → `slot_type`. |
| Mobile data | C `modem.set_connect` / `modem.disconnect {bus, slot}` | `lib.set_cellular_data_enabled`. |
| Roaming | C `modem.get_sim_config` / `set_sim_config` | `lib.apply_roaming`. |
| Airplane mode | Lua `system.set_airplane_mode {enable}` | `lib.set_network_attach_enabled(not airplane)`. |
| Main / guest Wi-Fi on/off | Lua `wifi.set_config {init, iface_name, enabled}` | Ifaces `wifi2g`, `wifi5g`, `guest2g`, `guest5g`. Triggers a full Wi-Fi reload (slow). |
| Rename guest Wi-Fi | Lua `wifi.set_config {iface_name, ssid, encryption, key, hidden, random_bssid, bssid}` | Current values come from `wifi.get_config`; only `ssid` changes. |
| Repeater | ubus `repeater scan` / `connect` / `disconnect` / `status` | Saved keys come from `/etc/config/repeater`. |
| VPN | uci `route_policy` + `wireguard.peer_*`, then `vpn-client` restart | `lib.set_wireguard_enabled`, the same path as the stock app. |
| Clients | ubus `gl-clients list` | Names, band, online state, totals, live rx/tx. |
| Block a device | Lua `black_white_list.set_single_mac {mode, operate:"add"\|"del", mac}` | In `"white"` (allow-list) mode the meaning is reversed. Read via `get_config` → `mode`, `black_mac`, `white_mac`. |
| AdGuard Home | Lua `adguardhome.get_config` / `set_config {enabled, dns_enabled}` | Stats (`:3000/control/stats`) need a web login, so they aren't shown. |
| Power | Lua `lpm.get_config` / `set_config {wifi_sleep_time, phy_sleep_time, auto_shutdown_time, power_plugin_turnon, system_sleep_enable}` | Send the whole form back. |
| USB | Lua `otg.get_config` / `set_config {protocol, data_role, pwr_role, pwr_role_c2, threshold}` | `data_role`: `askme`/`device`/`host`; `pwr_role`: `Sink` (input) / `Source` (output); protocols from `system.get_usb_info`. |
| Ethernet port | Lua `cable.get_ports_config` / `set_port_config {name, mode, macaddr \| vlan_mode+pvid}` | Built like the web page's `buildPortPayload`. |
| Brightness | sysfs `/sys/class/backlight/soc:backlight/brightness` (max 120) | |
| Weather | Open-Meteo forecast + air-quality APIs | |
| City search | Photon (`photon.komoot.io`), then Open-Meteo geocoding as a fallback | Open-Meteo geocoding times out from this network. |
| Exchange rates | open.er-api.com (`/v6/latest/USD`) | `lib.fetch_fx`; every conversion goes through USD (`lib.rate_between`), so any code in the list works. |
| Wi-Fi QR | `qrencode -t ASCII` | Parsed into a module grid; standard `WIFI:T:WPA;S:…;P:…;;` text with `\;,:"` escaped. |

## Config

`/root/e5ui/config.json` (defaults in `DEFAULTS` in `app.py`):

| Key | Meaning |
|---|---|
| `tz` | Main clock time zone (`Asia/Manila`) |
| `city`, `recent` | Weather city `{name, country, region, lat, lon}` and the last 3 |
| `two_clocks`, `clock2` | Second clock on Home, `[name, tz]` |
| `h24` | 24-hour time |
| `sig` | Personal signature |
| `wake` | Lock screen style: `Clock` / `Status` |
| `sms_read` | IDs of texts already read (last 300) |
| `pin`, `pass_on` | 4-digit passcode (stored as plain text) and whether it's required |
| `auto_lock`, `always_on` | Seconds of inactivity before the screen turns off (`null` = never); override |
| `caps` | Data caps in GB per `sim1` / `sim2` / `esim` (`null` = none) |
| `fx` | Currency compared with the main currency |
| `accent`, `accent_custom` | Accent color: a name from `ACCENTS` or `custom` + an `[r, g, b]` list. `apply_accent()` reassigns the module globals `TEAL`, `TEAL2`, `TEALBG`, `CHIPBG`, `CHIPFG`, `ON_ACCENT` (read at draw time); `accent_fix()` lightens dark colors (brightness >= 60%) |
| `home_fx` | Main currency the Currency page converts into (default `PHP`; list `FX_NAMES`; pickers `v_fx_home` / `v_fx_cmp` through `fx_list`) |
| `bright` | `Low` / `Medium` / `High` |
| `vpn_peer` | Unused since 2026-11-25: the tunnel's server is stored on the router (`lib.get_vpn_tunnel()["peer"]`) |
| `wallpaper`, `wall_on` | `Earth` / `Plain` / `Your own`; `Lock screen` / `Lock + Home` |

## Working on it

Deploy a change:

```sh
cd ~/Documents/e5800-screen
python3 -m py_compile router/app.py
scp -O router/app.py root@10.10.1.1:/root/e5ui/
ssh root@10.10.1.1 /etc/init.d/e5ui restart
```

Preview every screen as PNGs without touching the display (writes `contact.png` too):

```sh
ssh root@10.10.1.1 'cd /root/e5ui && python3 app.py --preview /tmp/e5pv'
scp -O 'root@10.10.1.1:/tmp/e5pv/*.png' ./preview/
```

Capture what's on the physical screen right now:

```sh
ssh root@10.10.1.1 'head -c 153600 /dev/fb0' > fb.raw
python3 -c "
from PIL import Image
b = open('fb.raw', 'rb').read()
px = [(((v >> 11) & 31) << 3, ((v >> 5) & 63) << 2, (v & 31) << 3) for v in (b[i] | b[i+1] << 8 for i in range(0, len(b), 2))]
im = Image.new('RGB', (240, 320)); im.putdata(px); im.save('screen.png')"
```

Conventions:

- **Copy the stock firmware's calls.** Find the call in `/www/views/*.js.gz` and send the same payload,
  usually the whole form read back from `get_config`. Raw `uci set` works, but leaves the stock screen and
  web UI showing stale state.
- **Confirm anything disruptive** (cuts a connection, costs money, blocks a device), and **verify** with a
  poll (`lib._wait_until`) rather than trusting the call's return.
- **Read-only probing on the live router is fine; changing settings there isn't** without asking: SIM
  switching drops mobile data, and blocking the wrong client cuts off SSH.
- Long jobs: `work()` runs one job at a time (a second says "Still working"); `busy_modal()` is true while the overlay is up; `busy_can_hide` is set for `work()` jobs and not for `power()`; `BUSY_HINTS` carries estimates only where measured. QR pages (`draw_qr`, `v_admin_qr`, `v_ts_login`) leave a 4-module quiet zone when modules stay >= 3 px.
- Chips are 17 px tall; note rows use a 16 px line height; the wallpaper takes a `scrim` (an eased black gradient over the top 130 px, strength 0.75 on Home and lock) so the date and weather stay readable over the bright planet edge.
- Check layouts at the bumped font sizes; `fit()` truncates with "…" rather than overflowing.

## Fresh install

You need `python3`, `python3-pillow` (installed with `--nodeps`, because the stock screen package already
owns a bundled libfreetype), `libtiff6`, all five `zoneinfo-*` packages and `qrencode`.

```sh
ssh root@10.10.1.1 'opkg update && opkg install python3 libtiff6 qrencode zoneinfo-asia zoneinfo-europe \
  zoneinfo-america zoneinfo-australia-nz zoneinfo-pacific && opkg install --nodeps python3-pillow \
  && mkdir -p /root/e5ui/cache'
scp -O router/*.py router/*.sh root@10.10.1.1:/root/e5ui/
scp -O router/init.d/* root@10.10.1.1:/etc/init.d/
ssh root@10.10.1.1 'chmod +x /root/e5ui/* /etc/init.d/e5ui /etc/init.d/homebutton;
  /etc/init.d/homebutton enable; /etc/init.d/homebutton start; /root/e5ui/toggle.sh on'
```

A firmware update may remove the packages or the init scripts. If the stock screen comes back after one,
rerun the steps above.

**As a package instead:** `packages/build.sh` builds an `.ipk` that does the same (see `packages/README.md`); after a firmware update one `opkg install` of that file restores it. It was installed on the router for real on 2026-11-25 (over the manual install, nothing changed); removing and upgrading it are untested.

## Troubleshooting

| Problem | Check |
|---|---|
| Stock screen is showing | `ssh root@10.10.1.1 /root/e5ui/toggle.sh status`. If `e5ui` stopped after crashes: `logread -e e5ui`, then `toggle.sh on`. |
| App errors | `logread \| grep -E "e5ui\|render error"`. Run `python3 /root/e5ui/app.py --preview /tmp/x` by hand to see a traceback. |
| Screen frozen or dark | Tap the power button (`screen_sleep.sh` controls the backlight and `fb0/blank`). `/etc/init.d/e5ui restart`. |
| Taps don't register | Touch is `/dev/input/event0`; the reader logs "touch reader stopped" on failure. Restart the service. |
| Weather or city search empty | `curl` to `api.open-meteo.com` / `photon.komoot.io` from the router; the screen shows cached data or "Loading". |
| Wi-Fi change slow | Expected: the firmware reloads all Wi-Fi (QCMAP, firewall, dnsmasq). The toggle spins until it finishes. |
| eSIM shows a generic name | `modem.get_profile_info` returns "Curl request failed" on this firmware. |

## Known gaps

- eSIM carrier/profile name (see above).
- AdGuard Home stats (need a web login).
- The passcode is a convenience lock: it's stored in plain text in `config.json`, and anyone with SSH or
  the admin panel can bypass it.

## Refresher gotcha

`lib.Refresher` keeps the previous value when a job returns `None` (it treats None as a failed run). For a job where
None is a real answer (no VPN connected, no tunnel), register it with `none_ok=True`; a raised exception still keeps the old value.
